grid-template-columns

개요

grid-template-columns는 열의 개수와 너비를 지정할 때 사용한다.

그리드 컨테이너에 지정하며, 기본값은 none이다.

Syntax

Values

grid-template-columns는 특수한 경우(상품 페이지처럼 행이 무한히 생성)가 아니면 보통 grid-template-rows와 같이 사용한다.

grid-template-columns만 사용하면 명시적 열만 설정되고, 행은 자동 배치에 따라 암시적으로 생성된다. 이때 암시적 행의 높이는 auto 처리된다.

max-content

열(Column) 트랙의 너비를 해당 열에 포함된 자식 엘리먼트들의 최대 콘텐츠 너비(max-content)에 맞춰 설정한다. 텍스트 줄바꿈 없이 콘텐츠가 가진 최대 너비만큼 트랙이 확장된다.

max-content는 자식 엘리먼트 콘텐츠의 고유 크기(Intrinsic Size)를 최우선으로 보장하기 때문에 컨테이너가 작으면 오버플로우가 발생할 수 있다.

min-content

열(Column) 트랙의 너비를 해당 열에 포함된 자식 엘리먼트들이 가질 수 있는 최소 너비(min-content)에 맞춰 설정한다. 텍스트 단어 중 가장 긴 단어의 너비에 맞춰 트랙이 최소한으로 줄어들고 나머지 단어는 줄바꿈된다.

minmax()

열의 최소 너비와 최대 너비를 범위로 지정한다. 첫 번째 인수가 최소 너비, 두 번째 인수가 최대 너비다.

auto-fill과 auto-fit

repeat() 함수와 함께 사용할 때 컨테이너 너비에 맞춰 열(Column)의 개수를 자동으로 계산하여 배치한다. 창 크기나 컨테이너 너비가 변하면 열 개수가 가변적으로 반응한다.

두 값 모두 컨테이너 공간이 부족하면 자동으로 줄바꿈(Wrap)되지만, 아이템 개수가 적어서 **컨테이너에 빈 공간이 남을 때** 서로 다르게 반응한다.

  • auto-fill: 아이템이 채워지고 공간이 남더라도, 트랙 너비 기준에 맞춰 빈 트랙(Gaps)을 계속 유지하고 생성한다.
  • auto-fit: 남는 빈 트랙들을 0px로 축소(Collapse)시키고 기존 아이템 트랙을 확장하여 컨테이너 빈 공간을 가득 채운다.

1. 기본 작동 방식

minmax(150px, 1fr)처럼 1fr과 조합하면 컨테이너 폭에 따라 열 개수가 자동 조절될 뿐만 아니라, 남는 여백을 기존 아이템들이 나눠 가가지며 컨테이너 전체 너비를 여백 없이 가득 채운다.

2. 컨테이너 너비에 따른 자동 열 개수 조정

minmax 없이 고정 너비(130px)만 사용하더라도, 컨테이너 너비가 넓어짐에 따라 130px 트랙이 들어갈 수 있는 개수를 자동 계산하여 1열, 2열, 3열로 열 수가 자동 조절된다.

auto-fill (repeat(auto-fill, 130px))
