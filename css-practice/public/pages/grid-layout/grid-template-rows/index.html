grid-template-rows

개요

grid-template-rows는 행의 개수와 높이를 설정할 때 사용한다.

그리드 컨테이너에 지정하며, 기본값은 none이다.

Syntax

Values

grid-template-rows는 특수한 경우가 아니면 보통 grid-template-columns와 같이 사용한다.

grid-template-rows만 단독으로 지정하면 명시적 행의 개수와 높이만 정해지고, 열의 크기는 지정하지 않은 상태가 된다. 자동 배치 과정에서 필요한 암시적 열의 너비는 기본적으로 auto로 처리된다.

max-content

행(Row) 트랙의 높이를 해당 행에 포함된 자식 엘리먼트들의 최대 콘텐츠 높이(max-content)에 맞춰 설정한다. 내부 콘텐츠의 높이에 맞춰 트랙 높이가 결정된다.

max-content는 자식 엘리먼트 콘텐츠의 고유 크기(Intrinsic Size)를 최우선으로 보장하기 때문에 컨테이너가 작으면 오버플로우가 발생할 수 있다.

min-content

1개의 열 구조에서 행(Row) 트랙의 높이를 최소 콘텐츠 높이(min-content)에 맞춘다. 줄바꿈된 콘텐츠가 차지하는 수직 높이만큼만 트랙이 딱 맞춰서 축소된다.

minmax()

행의 최소 높이와 최대 높이를 범위로 지정한다. 첫 번째 인수가 최소 높이, 두 번째 인수가 최대 높이다.

이 값을 지정하면 컨테이너의 높이 변화에 따라 행 트랙의 높이가 지정한 범위 안에서 커지거나 줄어든다.

auto-fill과 auto-fit

grid-template-rows에서 repeat() 함수와 함께 사용할 때 명시적인 컨테이너 높이(height)에 맞춰 행(Row)의 개수를 자동으로 계산하여 배치한다.

수평 축과 달리 행 배치에서는 줄바꿈(Wrap)에 의해 아이템 위치가 가로/세로로 전환되는 반응형 행 변화는 일어나지 않는다. 대신 **컨테이너 높이에 따라 생성되는 트랙의 개수와 남는 수직 공간의 분배 방식**에 차이가 생긴다.

  • auto-fill: 아이템이 채워지고 공간이 남더라도, 기준 높이에 맞춰 빈 행 트랙(Gaps)을 계속 유지하고 생성한다.
  • auto-fit: 남는 빈 행 트랙들을 0px로 축소(Collapse)시키고 기존 아이템 트랙을 확장하여 컨테이너 수직 공간을 가득 채운다.

minmax(50px, 1fr)처럼 1fr과 조합하면 컨테이너 높이에 맞춰 행 트랙이 계산된다. 남는 수직 여백이 발생할 경우 이를 아이템들이 나눠 가가지며 컨테이너 높이를 가득 채운다.
