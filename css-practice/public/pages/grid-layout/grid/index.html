grid

개요

grid는 모든 명시적(explicit) 및 암시적(implicit) 그리드 속성을 설정하는 단축 프로퍼티(shorthand property)다.

grid-template-areas, grid-template-rows, grid-template-columns, grid-auto-flow, grid-auto-rows, grid-auto-columns를 한 번에 설정할 수 있다.

구문 해석 형태는 세 가지로 나뉜다.

ℹ️ auto-flow는 grid 단축 프로퍼티(Shorthand) 전용 구문 키워드다. 브라우저가 grid 단축 프로퍼티를 해석할 때 슬래시(/) 기준으로 어느 쪽을 자동 흐름(Implicit Grid)으로 처리할지 구분하기 위한 식별자로 쓰인다.

슬래시 오른쪽(열 영역)에 auto-flow가 있는 경우 열 방향으로 자동 확장하라는 의미다.

반대로, 슬래시 왼쪽(행 영역)에 auto-flow가 있는 경우 행 방향으로 자동 확장하라는 의미가 된다.
