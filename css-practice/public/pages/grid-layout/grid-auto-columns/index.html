grid-auto-columns

개요

grid-auto-columns는 그리드 컨테이너에서 명시적으로 크기를 정의하지 않은 암시적 그리트 열의 크기를 설정할 때 사용하는 프로퍼티다.

grid-template-columns로 지정한 영역을 벗어나 아이템이 넘쳐서(overflow) 새로 생성되는 열의 너비를 통제한다.

그리드 컨테이너에 지정하는 프로퍼티고, 기본값은 auto

특이사항

⚠️ grid-auto-flow와의 관계

기본적으로 grid-auto-flow는 row로 설정되어 있다. 따라서 아이템이 넘치면 행(Row)이 추가되므로, 이때는 grid-auto-rows가 작동한다.

grid-auto-columns가 실제로 적용되려면 grid-auto-flow: column 설정을 통해 아이템이 오른쪽(열 방향)으로 추가되도록 만들거나, 개별 아이템에 명시적으로 지정한 열 번호(예: grid-column: 5)가 명시적 그리드 범위를 초과해야 한다.

오버플로우 처리

grid-auto-flow: column 상태에서 열이 지속적으로 추가되면 컨테이너 너비를 초과하여 가로 스크롤(Overflow)이 발생할 수 있으므로 Layout 설계 시 유의해야 한다.
