grid-auto-flow

개요

grid-auto-flow는 Grid 컨테이너에서 배치 위치가 명시적으로 지정되지 않은 자동 배치 아이템(auto-placed items)을 어떤 방향으로, 어떤 흐름 규칙에 따라 배치할지 결정하는 프로퍼티다.

이 프로퍼티는 grid-column이나 grid-row를 지정하지 않은 아이템들의 배치 축(행 또는 열)을 설정하거나, 빈 공간을 채우는 재배치 메커니즘을 활성화할 때 사용한다.

그리드 컨테이너에 지정한다. 기본값은 row

특이사항

implicit track의 영향

grid-auto-flow: column 설정 시 열 방향으로 트랙이 계속 확장되므로, 명시적 트랙 크기 설정을 원한다면 grid-template-columns 대신 grid-auto-columns를 함께 정의해야 크기를 제어할 수 있다.

dense (row dense)

Item 2가 2행으로 밀려나면서 1행 우측에 생긴 빈 공간(1칸)을 채우기 위해, 뒤에 나오는 1칸짜리 Item 3을 1행으로 끌어올린다.

dense 키워드의 시각적 순서 변경(Visual Reordering)

dense 알고리즘을 사용하면 DOM 트리의 실제 HTML 요소 순서와 화면에 렌더링되는 시각적 순서가 달라진다. 이는 키보드 탭(Tab) 이동 순서나 스크린 리더의 접근성(Accessibility) 읽기 순서에 영향을 줄 수 있으므로 접근성이 중요한 UI 구성 시 주의해야 한다.
