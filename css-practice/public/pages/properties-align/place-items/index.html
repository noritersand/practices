place-items

개요

place-items는 그리드나 플렉스박스 레이아웃에서 컨테이너 내부의 자식 엘리먼트들에 대해 블록 방향(align-items)과 인라인 방향(justify-items)의 정렬을 한 번에 설정할 때 사용하는 단축 프로퍼티다.

공백을 기준으로 좌측이 align-items, 우측이 justify-items로 해석된다.

컨테이너에 지정하는 프로퍼티고, 프로퍼티를 생략했을 때의 기본값은 normal이다.

특이사항

값 지정 방식

하나의 값만 지정하면 align-items와 justify-items 모두에 동일한 값이 적용된다. 두 개의 값을 지정하면 첫 번째 값은 align-items(수직/블록 방향), 두 번째 값은 justify-items(수평/인라인 방향)로 작동한다.

사실상 그리드 전용 프로퍼티

일반 레이아웃(Block/Inline)에서는 기본적으로 정렬 개념이 적용되지 않거나 효력이 없으므로, 주로 그리드 컨테이너 및 플렉스 컨테이너에서 자식 엘리먼트들의 교차 축 및 주 축 정렬을 제어하기 위해 사용한다. 플렉스 컨테이너에서는 justify-items 프로퍼티가 작동하지 않으며, 첫 번째 값인 align-items만 교차 축 정렬에 작동하고, 두 번째 값은 무시된다.
