justify-self

개요

justify-self는 정렬 컨테이너 내부의 개별 아이템에 적용하여 해당 아이템의 인라인 축(Inline Axis, 가로 방향) 정렬 방식을 설정하는 프로퍼티다.

자식 엘리먼트(개별 아이템)에 지정하는 프로퍼티며, 기본값은 auto다.

Grid 레이아웃의 그리드 아이템 및 Absolute 포지셔닝 요소, 일반 블록 레이아웃 등에서 개별 정렬을 제어할 때 사용된다. 단, Flexbox 레이아웃의 자식 엘리먼트에서는 justify-self 설정이 완전히 무시된다(Flexbox에서는 주축 정렬을 컨테이너 단위의 justify-content나 margin: auto로 제어함).

특이사항

Flexbox 레이아웃에서의 무시

Flexbox 레이아웃에서는 자식 아이템에 justify-self를 지정하더라도 완전히 무시된다. Flexbox에서 인라인 축 정렬은 부모의 justify-content나 자식의 margin: auto를 활용해야 한다.

Grid 레이아웃 및 절대 위치 지정(Absolute Positioning) 요소에서의 작동

주로 CSS Grid의 개별 아이템 정렬에 사용된다. 또한 position: absolute 또는 fixed가 적용된 요소에서 포지셔닝 영역 내 정렬을 제어할 때도 작동한다.

Basic keywords

auto

기본값으로, 부모 컨테이너의 justify-items 값을 그대로 상속받아 적용한다. 부모에 지정된 값이 없으면 normal로 작동한다.

normal

Grid Normal 2

stretch

너비(width)가 명시적으로 지정되지 않은 경우, 아이템이 속한 정렬 영역의 인라인 축 전체 너비를 채우도록 늘어난다.
