align-content

개요

align-content는 블록 컨테이너, 플렉스 컨테이너, 그리드 컨테이너 내부의 트랙이나 줄(Line) 전체를 블록 축(수직 방향)으로 어떻게 정렬할지 결정하는 프로퍼티다.

일반 블록 레이아웃에서는 자식 블록 요소 전체를 컨테이너 내부에서 수직 정렬할 때 사용된다. 플렉스박스에서는 flex-wrap: wrap 상태에서 여러 줄로 배치된 플렉스 라인 간의 간격을 정렬하며, 그리드 레이아웃에서는 그리드 콘텐츠 전체의 수직 트랙 정렬을 제어한다.

부모 엘리먼트(컨테이너)에 지정하며, 생략했을 때의 기본값은 normal

특이사항

플렉스박스에서의 작동 조건

플렉스 컨테이너에서 align-content가 작동하려면 flex-wrap: wrap 또는 wrap-reverse가 설정되어 있어야 하며, 교차 축에 여유 공간이 존재해야 한다. 단일 줄(flex-wrap: nowrap) 상태에서는 작동하지 않는다.

align-items와의 차이점

align-items는 개별 줄이나 트랙 내부에서 아이템 각각의 정렬을 제어하지만, align-content는 줄이나 트랙 전체 패키지의 정렬 및 분배를 제어한다.
