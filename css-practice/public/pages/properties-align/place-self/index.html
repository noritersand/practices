place-self

개요

place-self는 그리드나 플렉스박스 레이아웃에서 컨테이너 내부의 개별 자식 엘리먼트(그리드 아이템 또는 플렉스 아이템)에 대해 블록 방향(align-self)과 인라인 방향(justify-self)의 정렬을 한 번에 설정할 때 사용하는 단축 프로퍼티다.

공백을 기준으로 좌측이 align-self, 우측이 justify-self로 해석된다.

자식 엘리먼트에 직접 지정하는 프로퍼티고, 프로퍼티를 생략했을 때의 기본값은 auto이다.

특이사항

값 지정 방식

하나의 값만 지정하면 align-self와 justify-self 모두에 동일한 값이 적용된다. 두 개의 값을 지정하면 첫 번째 값은 align-self(수직/블록 방향), 두 번째 값은 justify-self(수평/인라인 방향)로 작동한다.

레이아웃별 작동 방식

일반 레이아웃(Block/Inline)에서는 개별 정렬 개념이 정해지지 않으므로 효력이 없으며, 주로 그리드 및 플렉스 레이아웃에서 개별 아이템의 정렬을 제어하기 위해 사용한다. 플렉스 레이아웃에서는 justify-self 프로퍼티가 작동하지 않으므로, 첫 번째 값인 align-self만 교차 축 정렬에 작동하고 두 번째 값은 무시된다.
