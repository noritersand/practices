align-items

개요

align-items는 플렉스(Flex) 및 그리드(Grid) 컨테이너 내부의 자식 엘리먼트(플렉스 아이템 또는 그리드 아이템)들을 교차 축(Cross Axis) 또는 블록 축(Block Axis) 방향으로 어떻게 정렬할지 일괄 지정하는 프로퍼티다.

부모 엘리먼트(컨테이너)에 지정하는 프로퍼티며, 프로퍼티를 생략했을 때 기본값은 normal이다 (일반적으로 stretch처럼 작동한다).

일반 레이아웃(Block, Inline)에서는 적용되지 않으며, 플렉스박스나 그리드 레이아웃 환경에서 자식 요소들의 정렬을 통제할 때 사용한다.

ℹ️ 플렉스박스에서 교차 축이 수직(세로)이 될지 수평(가로)이 될지는 flex-direction에 따라 달라진다. flex-direction이 row(기본값)일 때 교차 축은 수직이지만, flex-direction이 column일 때의 교차 축은 수평이다.

특이사항

일반 레이아웃(Block / Inline)에서의 무효화

일반적인 Block Flow 및 Inline 레이아웃에서는 align-items를 지정해도 완전히 무시(Ignored)된다. 반드시 부모 요소가 display: flex, display: inline-flex, display: grid, display: inline-grid 상태여야 작동한다.

일반 Block 레이아웃에서 수직 정렬을 하려면 Flex/Grid로 전환하거나, margin 또는 padding을 활용해야 한다.

flex-start / flex-end vs start / end

flex-start와 flex-end는 Flexbox 스펙에서 시작된 키워드다. Modern Grid 및 Flexbox에서는 논리적 방향 키워드인 start와 end의 사용을 권장한다.

overflow alignment (safe / unsafe)

아이템이 컨테이너 크기보다 커서 오버플로우가 발생할 때, safe 키워드를 붙이면 컨테이너 시작점을 벗어나 잘려나가는 영역을 방지하기 위해 정렬을 start로 강제 전환한다.
