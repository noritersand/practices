align-self

개요

align-self는 단일 아이템의 교차 축(Cross Axis) 또는 블록 축(Block Axis) 정렬 상태를 설정하는 프로퍼티다.

부모 요소가 설정한 전체 정렬 속성(align-items)을 재정의(Override)하여 개별 아이템만의 독립적인 정렬 위치를 지정할 때 사용한다.

일반 레이아웃(Block/Inline)에서는 기본적으로 작동하지 않는다.

플렉스 아이템이나 그리드 아이템 직접 적용하는 프로퍼티다. 기본값은 auto

ℹ️ 플렉스박스에서 교차 축이 수직(세로)이 될지 수평(가로)이 될지는 flex-direction에 따라 달라진다. flex-direction이 row(기본값)일 때 교차 축은 수직이지만, flex-direction이 column일 때의 교차 축은 수평이다.

특이사항

일반 레이아웃

일반적인 Block/Inline 흐름에서는 align-self가 적용되지 않는다. 다만, Absolute / Fixed Positional 요소에서 Anchor Positioning 스펙을 사용하는 경우 예외적으로 작동할 수 있다.

플렉스박스

flex-direction 설정에 따라 교차 축의 방향이 달라지므로, row일 때는 수직 정렬, column일 때는 수평 정렬을 제어한다.

그리드

그리드 영역(Grid Area) 내부에서 아이템의 수직(Block Axis) 정렬을 제어한다. (justify-self는 Inline Axis 정렬을 담당)

safe center vs unsafe center

safe center는 정렬 시 컨테이너를 벗어나 넘치는 부분이 발생하면 start 정렬로 전환하여 넘친 콘텐츠가 화면 밖으로 가려지지 않게 보호한다.

unsafe center는 넘침 여부와 상관없이 무조건 중앙 정렬을 강제하여 상단이나 좌측 콘텐츠가 잘릴 수 있다.
