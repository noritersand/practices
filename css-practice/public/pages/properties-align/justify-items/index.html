justify-items

개요

justify-items는 Grid 컨테이너나 블록 컨테이너 내부의 모든 아이템들의 인라인(가로) 축 방향 정렬 방식을 일괄적으로 설정하는 프로퍼티다.

Flexbox 레이아웃의 컨테이너에 적용할 경우 이 프로퍼티는 무시된다. (Flexbox에서는 주축 정렬에 justify-content를 사용하며, 교차 축 개별 정렬에는 align-self를 사용한다.)

컨테이너에 적용하는 프로퍼티로, 생략했을 때의 기본값은 legacy(특수 문맥) 또는 normal이다. (Grid 컨테이너에서는 보통 stretch처럼 작동한다)

특이사항

Flexbox에서의 무시

Flexbox 컨테이너에 justify-items를 지정하더라도 아무런 효과가 나타나지 않는다. Flexbox 자식 요소의 가로/주축 정렬을 통제하려면 컨테이너의 justify-content나 개별 아이템의 정렬 프로퍼티를 활용해야 한다.

Overflow Alignment (safe / unsafe)

아이템의 크기가 컨테이너나 그리드 영역보다 커서 넘칠 때, safe 키워드를 함께 사용하면 정렬 방식을 start로 강제 전환하여 콘텐츠의 시작 부분이 화면 밖으로 잘려 나가는 현상을 방지한다. 반면 unsafe는 넘침 여부와 상관없이 지정한 정렬 위치를 강제로 유지하므로 데이터 손실(잘림)이 발생할 수 있다.
